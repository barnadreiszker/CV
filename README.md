# Barna Dreiszker - Personal CV & Portfolio Website

Online CV & Portfolio website for **Barna Dreiszker**, Business & Management student at Eötvös Loránd University (ELTE) and active member of the Budapest Investment Club (BIC).

## 🚀 Live Demo
Once GitHub Pages is enabled:
`https://barnadreiszker.github.io/cv/` (or repository name)

## 📁 Project Structure
- `index.html` - Main HTML layout and responsive structure
- `style.css` - Custom styling, glassmorphism, animations, and typography
- `script.js` - Interactive navigation, live year, and clipboard actions
- `Barna_Dreiszker_CV.pdf` - Downloadable curriculum vitae
- `barna-dreiszker.jpg` - Profile photo
- `*-logo*.png` - Institution and organization emblems (ELTE, BIC, Teleki)

## 💻 Local Preview
To preview locally, open `index.html` in your browser, or double click `start_website.bat`.
